# Rubin (VR200 / sm_107) pre-release dependencies.
#
# Consumed by docker/Dockerfile when INSTALL_RUBIN_PRERELEASE=true, added in
# vllm-project/vllm#53443. Contents are Shang Wang's, posted to #swdl-vllm-dev
# on 2026-08-27; they are the not-yet-released halves of the Rubin stack, and
# each is expected to be replaced by a public wheel as it ships.
#
# Why this file is what unblocks Kimi-K3 on Hecate, concretely. Every wall that
# track hit is one of these lines:
#
#   nvidia-cutlass-dsl 4.8   the CuteDSL that knows sm_107a. Without it, K3's
#                            latent-MoE tail fusion dies in cute.compile with
#                            KeyError: 'sm_107a'.
#   flashinfer-* nvinternal  the build carrying the SM107 cubins. Without them
#                            moe-backend auto fetches batched_gemm-fe08bc1 and
#                            gets a 404, so the engine never starts.
#   the CUDA 13.4/13.5 base  ptxas that has an sm_107 target at all. 13.0.88
#                            (upstream nightly) and 13.3.73 both lack it, so
#                            every Triton JIT fails after the weights load.
#
# Building upstream main with these also restores what the vendor Rubin image
# lacks: main's K3 plugin carries the DCP implementation and no assert against
# it, where the rubin-branch plugin has the assert and none of the code.
